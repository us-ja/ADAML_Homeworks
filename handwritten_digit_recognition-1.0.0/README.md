This is a very basic example of handwritten digit recognition using a simple 3-layer neural network built from scratch. All steps are implemented, no black box.

MLP.m is the training and testing algorithm

written\_digit\_recognition.m is a demo of the best trained network (provided) recognizing the digit written in a file you create. Draw a digit with your favorite image editor, save it next to the script, and it will open it and recognize the digit you've written.
